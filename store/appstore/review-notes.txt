Retro-3DO is a 3DO Interactive Multiplayer emulator. It ships no commercial
BIOS, no game images and no copyrighted ROM material. The reviewer needs
nothing external to see it working.

HOW TO SEE IT RUN, WITH NOTHING INSTALLED

1. Launch the app.
2. Tap Demo in the left-hand navigation rail.
3. Tap the button to start the built-in hardware demonstration.

It boots immediately. The status lines report the emulated hardware coming up,
and a marker appears that the on-screen D-pad moves; A, B and C change its
colour. No BIOS, no disc and no network access are required at any point.

USER-SUPPLIED CONTENT

A BIOS and disc images are supplied by the user, from storage they already
control, through the iOS Files app. The application downloads no executable
code and has no mechanism to do so.
