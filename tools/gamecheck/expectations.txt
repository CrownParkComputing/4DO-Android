# What each title reaches today, as a floor.
#
# These are NOT targets. They are a record of where the emulator got to on a
# twenty-thousand-frame headless run, written down so that losing ground is a
# test failure rather than something someone notices by eye three weeks later.
# A title that does better than its line is not a failure; a title that does
# worse is a regression.
#
# Raise a line when a title genuinely improves. Never lower one to make a run
# green - a lowered floor is a bug report deleted.
#
# Format:  name prefix | cels | distinct screens | busiest frame's lit pixels
#
# These numbers are for a TWENTY THOUSAND frame run. A shorter run will fail
# them, which is correct rather than a bug in the file: several titles take
# well over a minute of emulated time to reach anything.
#
# Run with:
#   gamecheck <bios> <library> --frames 20000 \
#             --expect tools/gamecheck/expectations.txt
#
# Status, honestly. "Matches reference" means the machine this was ported from
# does the same thing with the same dump, so the shortfall is not ours alone.
# Where a title has been compared frame-for-frame, the figure is how many of
# its pixels differ from the reference's on the same frame.
#
#   Killing Time          its title menu. 3.3% of pixels differ.
#   Flashback             its menu. 11% differ, and that is the character
#                         standing at a different point in his idle animation.
#   Alone in the Dark     its animated intro, over a million cels
#   PGA Tour 96           credits, clean
#   Alone in the Dark 2   drawing, mid-transition
#   Battle Chess          its publisher splash. Cel count within two per cent
#                         of the reference, so this is where the title gets to
#                         in five minutes rather than where we stop it.
#   BattleSport           BIOS shell, "Insert CD". MATCHES REFERENCE.
#   Road Rash             BIOS shell, "Insert CD". MATCHES REFERENCE.
#   Doom                  BIOS shell - the dump is bad, chdman rejects it too
#   Need for Speed        barely draws. The reference manages sixty-five cels
#                         to our thirty-three, so it does not work there
#                         either. Not ours alone to fix.
#   Wing Commander III    draws a starfield where the reference has a
#                         cutscene. OURS - the reference gets there.
#   Wing Commander III d2 will not open at all - suspect a bad dump
#
# Eleven of twelve draw. The one that does not is a bad file.
